# Инструкция по использованию split.py и merge.py

## Зачем нужны эти скрипты?
Moodle не принимает слишком большие XML-файлы с вопросами при импорте. Чтобы обойти это ограничение, вы можете:
- Разделить большой файл на несколько маленьких (split.py)
- Объединить несколько небольших файлов обратно в один (merge.py)

## split.py
Скрипт split.py делит исходный XML-файл с вопросами на 25 частей (или другое количество по вашему выбору). Это позволяет загружать вопросы в Moodle по частям, чтобы избежать ошибок из-за большого размера файла.

**Использование:**
1. Поместите исходный файл (например, `questions.xml`) в ту же папку, что и split.py.
2. Запустите скрипт:
   ```
   python split.py
   ```
3. В папке появятся файлы `questions_part1.xml`, `questions_part2.xml` и т.д.
4. Импортируйте их по очереди в Moodle.

## merge.py
Скрипт merge.py объединяет все файлы вида `questions_part*.xml` в один файл `questions_merged.xml`. Это удобно, если вы хотите собрать вопросы обратно в один файл после редактирования или загрузки.

**Использование:**
1. Поместите все нужные файлы `questions_part*.xml` в одну папку с merge.py.
2. Запустите скрипт:
   ```
   python merge.py
   ```
3. Получите итоговый файл `questions_merged.xml`.

---

**Важно:**
- Не пытайтесь импортировать в Moodle слишком большие файлы — делите их на части.
- Если нужно объединить несколько частей, используйте merge.py.
